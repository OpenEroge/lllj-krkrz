# layerexdraw

`layerExDraw.dll` (GDI+ drawing on layers: `Appearance`, `Pen`, `Brush`,
`Path`, `Matrix`, Layer drawing members), vendored from krkr-ns and rasterized by
[PlutoVG](third_party/plutovg/UPSTREAM.txt). Registered as the static plugin
`compat_layerexdraw`. `PathGradient` follows GDI+ (triangle fan from the centre
with barycentric colours). Text drawing has no fonts. Details: `src/UPSTREAM.txt`.
